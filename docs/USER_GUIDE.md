# מדריך קצר למשתמש: Smart Remote AI

שלט אחד בטלפון לטלוויזיה ולממיר. עובד בדפדפן, בלי להתקין אפליקציה מהחנות.

## 1. כניסה ראשונה (פעם אחת)

1. **פותחים את הקישור האישי** שקיבלתם מהמנהל (מי שמנהל את המערכת). הקישור מכניס אתכם אוטומטית וזוכר אתכם בדפדפן.
   - אין קישור? מבקשים. כל אדם (וכל מכשיר) מקבל קוד נפרד. בלי קוד האתר נשאר במצב הדגמה ולא שולט בכלום.
2. **מוסיפים למסך הבית** כדי שיתנהג כמו אפליקציה:
   - אייפון (Safari): כפתור השיתוף ← "הוסף למסך הבית".
   - אנדרואיד (Chrome): תפריט ⋮ ← "התקן אפליקציה" / "הוסף למסך הבית".
3. בכניסה למסך הבית תראו את **מפת החיבורים**: ירוק = מחובר, אדום = מנותק.

> אל תשתפו את הקישור האישי הלאה. אם הטלפון אבד, המנהל מבטל את הקוד שלו ולא נוגע בשאר.

## 2. השימוש היומיומי

| רוצים | עושים |
|---|---|
| להחליף ערוץ | לשונית **ממיר** ← לוחצים על הספרות, כמו בשלט רגיל. אפשר גם "ערוץ +/−" ו"אחרון" |
| להגביר או להנמיך | כפתורי העוצמה בלשונית ממיר או טלוויזיה (לפי מה שהמנהל קבע) |
| לפתוח YouTube, Netflix, Spotify | כרטיס **אפליקציות** |
| לחפש תוכן | **מקלדת וחיפוש** ← בוחרים אפליקציה ומקלידים מה לחפש |
| להקליד בחיפוש בטלוויזיה | **מקלדת וחיפוש** ← "הקלדה במסך" (כשיש שדה טקסט פעיל על המסך) |
| לנווט בתפריטים | חצים ו-OK, וכפתורי תפריט / מדריך / מידע |
| לכבות טלוויזיה | לשונית **טלוויזיה** ← כיבוי (שתי לחיצות, כדי לא לכבות בטעות) |

## 3. פקודות קוליות (לשונית "קול")

לוחצים על המיקרופון ואומרים, או מקלידים:

- "ערוץ 12" · "תגביר" · "תנמיך" · "השתק"
- "פתח יוטיוב" · "פתח נטפליקס בממיר"
- "חפש חתולים מצחיקים ביוטיוב"
- "כבה את הטלוויזיה בעוד שעה" (מתוזמן בשרת ונשמר גם אם הדפדפן נסגר)

תמיד רואים **תצוגה מקדימה** של מה שיבוצע, ולוחצים "בצע". הקול פועל רק לאחר לחיצה, והמיקרופון דורש חיבור מאובטח (HTTPS).

## 4. מצב ילדים

אם הקוד שלכם במצב ילדים, תראו למעלה כמה זמן נשאר היום ומתי מותר.

- מחוץ לשעות המותרות, או אחרי המכסה, הכפתורים נחסמים.
- לוחצים **"בקש עוד זמן"** ובוחרים 15, 30 או 60 דקות. ההורה מקבל את הבקשה ומאשר מהטלפון שלו.

## 5. למנהל (הגדרות)

- **קודי גישה למכשירים:** יוצרים קוד לכל בן משפחה, מעתיקים "קישור כניסה" ושולחים אליו. הקוד מוצג פעם אחת בלבד.
- **מצב ילדים:** שעות מותרות, אפליקציות מורשות, מכסה יומית, והאם מותר לכבות או לתזמן. נאכף בשרת.
- **בקשות זמן:** מופיעות בראש כרטיס הקודים (ונקודה אדומה על "הגדרות").
- **זמן מסך:** במסך הבית, לפי יום ולפי אפליקציה.
- **יומן פעילות:** כניסות כושלות, כניסה ממקום חדש, ושינויים חשובים.
- **מכשירים:** סריקת רשת, הוספה לפי כתובת IP, צימוד, שינוי שם ותפקיד, הסרה.

## 6. כשמשהו לא עובד

| מה רואים | מה עושים |
|---|---|
| "אין חיבור לשרת השלט" | המחשב שמריץ את המערכת כבוי או שאין לו אינטרנט. מודיעים למנהל |
| טלוויזיה אדומה במפה | כנראה כבויה. אם דלוקה: מחכים כדקה וחצי, המערכת מוצאת אותה לבד גם אם הכתובת שלה השתנתה |
| המקשים "לא עושים כלום" | לשונית ממיר או טלוויזיה ← **בדיקת חיבור**. אם הוא תקין והמסך לא מגיב, מוודאים שאתם באפליקציה הנכונה |
| "מחוץ לשעות המותרות" | מצב ילדים. מבקשים עוד זמן |
| ספוטיפיי נפתחת לדף התקנה | האפליקציה לא מותקנת במכשיר הזה. מתקינים אותה פעם אחת במכשיר |
| הכפתור צבוע אפור/כבוי | המכשיר מנותק או שהפעולה לא נתמכת בו |

## 7. טיפים

- "נשלחה" פירושו שהפקודה יצאה מהשרת. אם המסך לא הגיב, השתמשו ב"בדיקת חיבור".
- עוצמה בטלוויזיה שמחוברת למערכת סאונד חיצונית (אופטי) נשלטת במערכת הסאונד, לא דרך הטלוויזיה.
- מצב **הדגמה** (כתום) הוא סימולציה בלבד: לא נשלח דבר למכשירים.
