# Smart Remote AI

שלט אוניברסלי בדפדפן (PWA, עברית RTL) לטלוויזיות ולממירים ברשת הביתית: **LG webOS** ו-**Android TV / Google TV** (כולל סטרימרים וממירים כמו HOT Streamer).
React + TypeScript בצד הלקוח, Python FastAPI בשרת.

> **עיקרון מנחה:** "נשלחה" אינה "המכשיר הגיב". המערכת לא מציגה הצלחה מזויפת: יכולת שלא נבדקה מסומנת "לא נבדק", ויש מצב הדגמה מסומן בבירור.

## מה יש

- **שלט לכל תפקיד** (טלוויזיה / ממיר), לא תלוי במותג: ניווט, מדיה, מקשי תפריט, עוצמה, מקלדת ספרות מיידית, ערוצים מועדפים, ערוץ +/− ו"אחרון" (מדומים מספרות), פתיחת אפליקציות (YouTube, Netflix, Spotify), עכבר אמיתי ב-LG ומשטח החלקה מדמה ב-Android TV.
- **מפת חיבורים** חיה במסך הבית (שרת, רשת ביתית, כל מכשיר, עם סטטוס צבעוני ואנימציית פקודה).
- **קול ו-AI:** זיהוי דיבור בעברית (`he-IL`) עם חלופת הקלדה, פרסור דטרמיניסטי של פקודות, תזמון בשרת ("כבה את הטלוויזיה בעוד שעה"), וספק AI אופציונלי עם רשימת פעולות מותרות.
- **גילוי וצימוד:** סריקת רשת (mDNS ל-Android TV, SSDP ל-LG), הוספה לפי IP, צימוד, חיבור מחדש אוטומטי, ומעקב אחרי מכשיר שקיבל כתובת IP חדשה.
- **אבטחה:** קוד גישה ראשי + קודי גישה נפרדים לכל מכשיר (נשמרים כ-hash, ניתנים לביטול), יומן פעילות, חסימת ניחושים, הגבלת כתובות אופציונלית, הרשאות מנהל.
- **בדיקת חיבור** אמיתית (round trip, לא רק "נשלח") עם איפוס חיבור תקוע.

## ארכיטקטורה

```
דפדפן / PWA  ──HTTPS──▶  IIS (או כל reverse proxy)  ──▶  FastAPI (127.0.0.1)
                                                            ├─ Android TV Remote v2  (androidtvremote2)
                                                            └─ LG webOS SSAP          (aiowebostv)
```

- `frontend/` – React + Vite + Tailwind, PWA.
- `backend/` – FastAPI, SQLite, מתאמים למכשירים (`app/adapters`), תזמון, פרסור פקודות, אבטחה.
- `docs/` – ארכיטקטורה, רשימות בדיקה על מכשירים אמיתיים, יכולות מכשירים, מסמך האפיון (`PRD.md`).
- `ecosystem.config.js` – הרצת השרת ב-PM2.

פרטי הצימוד (תעודות, מפתחות LG) נשמרים בשרת בלבד (`backend/data/`), ואינם נחשפים לדפדפן או ללוגים.

## הרצה בפיתוח (Windows)

דרישות: Node.js 20+, Python 3.11+.

```powershell
# שרת (חלון ראשון)
cd backend
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
copy ..\.env.example ..\.env        # והגדר ACCESS_TOKEN
.\.venv\Scripts\python run.py        # 127.0.0.1:41500

# אתר (חלון שני)
cd frontend
npm install
npm run dev                          # http://127.0.0.1:5173  (מעביר /api לשרת)
```

מצב הדגמה (בלי מכשירים ובלי שרת) פועל מיד באתר. כדי לבדוק בלי חומרה: `USE_MOCK_ADAPTERS=true` (קוד צימוד HOT מדומה: `123456`).

## פריסה

- האתר נבנה (`npm run build`) ומוגש כקבצים סטטיים. ב-`frontend/.env.production` מוגדרים `VITE_BASE` (נתיב האפליקציה) ו-`VITE_API_BASE`.
- השרת רץ על `127.0.0.1` בלבד (PM2: `pm2 start ecosystem.config.js --env production`) ו-reverse proxy מעביר אליו `/<app>/api/*`. ב-IIS זה כלל rewrite ב-`frontend/public/web.config` (שימו לב ל-`<clear />` שמונע ירושת כללים מהאתר האב, ול-`existingResponse="PassThrough"` שמשאיר את הודעות השגיאה של השרת).
- `TRUST_PROXY=true` כשהשרת מאחורי proxy, כדי שכתובת הלקוח האמיתית תילקח מ-`X-Forwarded-For`.
- **אל תחשפו את השרת לאינטרנט בלי HTTPS וקוד גישה חזק.** ההנחיה בפרויקט: רשת ביתית בלבד, אלא אם בוצעה הקשחה מודעת (קודים לפי מכשיר, `ALLOWED_CIDRS`, יומן פעילות).

## הגדרות (`.env`)

| משתנה | משמעות |
|---|---|
| `ACCESS_TOKEN` | קוד הגישה הראשי (מנהל). חובה כשהשרת חשוף מעבר ל-localhost |
| `BACKEND_HOST` / `BACKEND_PORT` | כתובת והאזנה (ברירת מחדל `127.0.0.1:41500`) |
| `TRUST_PROXY` | להאמין ל-`X-Forwarded-For` כשהבקשה מגיעה מ-localhost |
| `ALLOWED_CIDRS` | רשימת רשתות מותרות (למשל `192.168.1.0/24`). ריק = ללא הגבלה |
| `ALLOWED_ORIGINS` | מקורות CORS מפורשים (אין `*`) |
| `LLM_API_KEY` / `LLM_MODEL` | ספק AI אופציונלי. בלי מפתח עובד הפרסר הדטרמיניסטי |
| `USE_MOCK_ADAPTERS` | מכשירי דמה בזיכרון לבדיקות |

## בדיקות

```powershell
cd backend ; .\.venv\Scripts\python -m pytest -q     # בדיקות שרת (מתאמים מול "מכשיר מזויף")
cd frontend; npm test                                 # פרסר פקודות
cd frontend; npm run e2e                              # smoke בדפדפן (דורש dev server)
```

בדיקות E2E נוספות ב-`frontend/e2e/` (ניקוי ובחירה מרובה, קודי גישה, מצב אמיתי) מקבלות `BASE_URL` / `ACCESS_TOKEN`.
**כל בדיקות המתאמים רצות מול מכשיר מזויף.** התנהגות מול חומרה אמיתית נבדקת ידנית, ורשימות הבדיקה ב-`docs/`.

## מגבלות ידועות

- הממיר אינו מדווח על הערוץ הנוכחי: "ערוץ +/−" ו"אחרון" מבוססים על הערוץ האחרון ששלח השרת.
- ב-LG שפלט הקול שלו מחובר לאופטי/ARC הטלוויזיה דוחה פקודות עוצמה והשתקה (וההודעה מוסברת בממשק).
- Android TV אינו תומך בעכבר: המשטח מדמה אותו בלחיצות על חצים.
- הפעלת טלוויזיה מרחוק (Wake-on-LAN) טרם מומשה. Apple TV, Roku, Fire TV ו-Samsung אינם נתמכים.
- אפליקציה שלא מותקנת בממיר (למשל Spotify) תפתח את דף ההתקנה שלה ב-Play Store.
